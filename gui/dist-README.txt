# Zapret GUI — краткая инструкция (сборка)

## Установка

ZapretGUI.exe v1.1.1 сам находит папку zapret — копировать его внутрь
НЕОБЯЗАТЕЛЬНО. Два рабочих варианта:

### Вариант А (проще всего)

1. Запустите ZapretGUI.exe откуда угодно.
2. Если рядом не найден bin\winws.exe, GUI автоматически поищет папку
   zapret рядом с exe (родительские папки до 3 уровней вверх + подпапки
   с «zapret» в имени).
3. Если не нашёл — появится диалог «Файлы zapret не найдены»:
   нажмите «Указать папку zapret…» и выберите папку, куда распакован
   сам zapret (внутри неё — bin\, lists\, файлы general*.bat).
   Папка запомнится в %APPDATA%\ZapretGUI\settings.ini и больше
   спрашивать не будет.

### Вариант Б (классический)

1. Положите ZapretGUI.exe в КОРЕНЬ папки zapret:

   ```
   C:\zapret\
   ├── ZapretGUI.exe        <- из этого архива
   ├── service.bat          <- из этого архива (модифицированный)
   ├── general.bat, general (ALT).bat, ...
   ├── bin\
   │   └── winws.exe
   ├── lists\
   └── utils\
   ```

2. Папка не должна содержать кириллицу (как и для оригинальных
   скриптов).

В обоих случаях запуск потребует прав администратора (UAC) — они
нужны для управления службами и обходом.

## Возможности

- Большая кнопка — включение/выключение обхода (winws.exe запускается
  скрытно, без всплывающих консолей)
- Закрытие окна сворачивает программу в ТРЕЙ — она продолжает работать.
  Левый клик по значку возвращает окно; полный выход — правой кнопкой
  по значку -> «Полный выход». Значок в трее показывает состояние
  (зелёное кольцо = обход включён). Повторный запуск exe просто
  разворачивает уже открытое окно (второй копии не появляется).
- Выбор языка интерфейса: Русский / English — на лету
- Выбор темы: Тёмная / Светлая / Полночь — на лету
- Выбор стратегии (список general*.bat), выбор запоминается
- Игровой фильтр: Отключён / UDP / TCP / TCP и UDP
- Автозапуск с Windows — установка/удаление службы zapret
- Проверка обновлений: флаг + ручная проверка версии
- Фильтр IPSet: Загружен / Отключён / Любой IP
- Диагностика и Тесты — открываются в консоли (нужен модифицированный
  service.bat из этого архива)
- Обновление hosts и IPSet — скачивание без окон консоли
- Журнал событий — цветной лог всех действий

## Замечания

- Оригинальные general*.bat и service.bat (меню) продолжают работать
  как раньше — GUI использует те же файлы состояния.
- Сборка производилась MinGW-w64 (GCC 14.2, x86_64, статическая CRT) —
  дополнительных DLL не требуется, только стандартные библиотеки Windows.
- Окно компактное: по вертикали умещается на 720p-монитор (высота 672 DU
  + заголовок), ширина прежняя (660 DU); настройки сгруппированы попарно
  (игровой фильтр + IPSet, автозапуск + проверка обновлений, язык + тема).
- Устранены мерцание нижнего ряда кнопок и «троение» надписи «Проверить
  обновления» при наведении (двойная буферизация контролов; перерисовка
  таймера статуса только при реальных изменениях).
- Совместимость: Windows 7 SP1 x64 и новее (только x64).
- Поддерживается масштабирование DPI (100% / 125% / 150% / 200%).
- Для проверки обновлений на Windows 7 SP1 в WinHTTP явно включается
  TLS 1.2 (без правки реестра).
- Если при запуске файлов zapret рядом нет, GUI сам ищет папку zapret
  и предлагает выбрать её вручную; кнопка «ВКЛЮЧИТЬ ОБХОД» в этом
  состоянии превращается в «ВЫБРАТЬ ПАПКУ ZAPRET». Точный список
  проверенных папок печатается в журнале событий.
- Сброс выбранной папки — удалите секцию [zapret] в файле
  %APPDATA%\ZapretGUI\settings.ini. Язык и тема хранятся там же
  ([gui] language=ru|en, theme=dark|light|midnight).
