# Zapret GUI — графический интерфейс

Современный GUI для **zapret-discord-youtube** (обход блокировок Discord и
YouTube). Написан на чистом **C++ / Win32 API** без внешних зависимостей —
один компактный `ZapretGUI.exe`, ничего устанавливать не нужно.

Дизайн: хромированная тёмная тема (глянец, 3D-выпуклые кнопки, мягкие
тени, градиенты по скруглениям), компактное окно 660×672 условных единиц
(умещается на 720p-монитор по вертикали вместе с заголовком) с поддержкой
масштабирования DPI. Настройки сгруппированы попарно: игровой фильтр и
IPSet, автозапуск и проверка обновлений, язык и тема — чтобы всё
оставалось на виду без прокрутки.

**Совместимость:** Windows 7 SP1 x64 и новее (только x64). Все
необязательные API (TaskDialog, DWM, IFileDialog, WinHTTP TLS 1.2)
загружаются динамически или имеют фолбэки — на Windows 7 ничего не рушится.

## Возможности

| Раздел | Что делает |
|---|---|
| **Главная кнопка** | Включение/выключение обхода — запуск `bin\winws.exe` напрямую, без всплывающих консолей |
| **Свернуть в трей** | Закрытие окна (крестик) сворачивает программу в трей: она продолжает работать; полный выход — правой кнопкой по значку → «Полный выход». Левый клик по значку возвращает окно |
| **Язык интерфейса** | Русский / English — переключение на лету, запоминается в настройках |
| **Тема оформления** | Тёмная / Светлая / Полночь — переключение на лету, запоминается |
| **Стратегия обхода** | Выпадающий список всех `general*.bat` (естественная сортировка), запоминается выбор |
| **Статус-карточки** | Процесс winws / служба zapret / драйвер WinDivert — обновляются каждые 2 секунды |
| **Игровой фильтр** | Отключён / UDP / TCP / TCP и UDP (`utils\game_filter.enabled`) |
| **Автозапуск (служба)** | Установка и удаление службы `zapret` с выбранной стратегией (автозапуск Windows) |
| **Проверка обновлений** | Флаг `utils\check_updates.enabled` + ручная проверка версии в журнале |
| **Фильтр IPSet** | Загружен / Отключён / Любой IP (`lists\ipset-all.txt` + `.backup`) |
| **Журнал событий** | Цветной лог всех действий (успех/предупреждение/ошибка) |
| **Диагностика / Тесты** | Интерактивные консоли `service.bat diag` и `service.bat tests` |
| **Обновить hosts / IPSet** | Скачивание из репозитория средствами WinHTTP, без окон консоли |

Повторный запуск `ZapretGUI.exe` не плодит вторую копию — просто
разворачивает уже открытое (в т.ч. скрытое в трей) окно.

## Сборка

### Windows (MinGW-w64)

Требуется `g++` и `windres` из [MSYS2](https://www.msys2.org/)
(`pacman -S mingw-w64-x86_64-gcc`) или сборки
[winlibs.com](https://winlibs.com/):

```bat
cd gui
build.bat
```

Готовый файл: `gui\build\ZapretGUI.exe`.

### Linux (кросс-компиляция)

Требуется пакет `mingw-w64` (например, `sudo apt install mingw-w64`):

```bash
cd gui
./build.sh
```

### GitHub Actions (ручной режим)

В репозитории есть workflow `.github/workflows/build-gui.yml`
(**Build Zapret GUI (x64)**) с триггером `workflow_dispatch`. Ресурс
сборки — кросс-инструментарий MinGW-w64 (`x86_64-w64-mingw32-g++` +
`windres`, статическая CRT; библиотеки gdiplus / winhttp / shell32 /
gdi32 / user32 / comctl32 / advapi32 / ole32) — на раннере
`ubuntu-latest` ставится пакетом `mingw-w64`.

Запуск: вкладка **Actions → Build Zapret GUI (x64) → Run workflow**.
Артефакты: `zapret-gui-compiled-x64` (готовый exe + service.bat +
README) и снапшот исходников. Опционально можно указать тег релиза —
тогда сборка прикрепляется к GitHub Release.

## Установка

1. Запустите `ZapretGUI.exe`. **Копировать exe в корень папки zapret
   необязательно** — если рядом не найден `bin\winws.exe`, GUI:
   - автоматически поищет папку zapret рядом с exe (включая папки
     родителей до 3 уровней вверх и подпапки с «zapret» в имени);
   - если не нашёл — предложит выбрать папку zapret в диалоге
     («Указать папку zapret…»), после выбора запомнит её в
     `%APPDATA%\ZapretGUI\settings.ini` и больше спрашивать не будет.
2. Классический вариант тоже работает: положите `ZapretGUI.exe` в
   корень папки zapret (рядом с `service.bat` и `general*.bat`).
3. Убедитесь, что `service.bat` — модифицированная версия из этого
   репозитория (добавлены аргументы `diag` и `tests` для кнопок
   «Диагностика» и «Тесты»).
4. Запуск потребует разрешения администратора (UAC): работа со
   службами и файлом hosts требует прав.

### Если появилось «Файлы zapret не найдены»

Это значит, что в папке, откуда запущен `ZapretGUI.exe`, нет
`bin\winws.exe`. В окне нажмите **«Указать папку zapret…»** и выберите
папку, куда распакован сам zapret (внутри неё — `bin\`, `lists\`,
файлы `general*.bat`). Выбранная папка запомнится. То же самое можно
сделать позже кнопкой **«ВЫБРАТЬ ПАПКУ ZAPRET»** в самом GUI. Сброс
выбора — удалите секцию `[zapret]` в `%APPDATA%\ZapretGUI\settings.ini`.

- **1.1.1**: окно стало компактным (660×672 DU — помещается на 720p
  по вертикали, ширина не изменилась), настройки сгруппированы в 4 строки
  (попарно: игровой фильтр + IPSet, автозапуск + проверка обновлений,
  язык + тема); устранено периодическое мерцание нижнего ряда кнопок
  (двойная буферизация всех контролов + WS_CLIPCHILDREN + перерисовка
  таймера статуса только при реальных изменениях); устранено «троение»
  ссылки «Проверить обновления» при наведении (ранее текст рисовался
  поверх старого без очистки фона); иконка трея больше не обновляется,
  если состояние не менялось.
- **1.1.0**: закрытие окна теперь сворачивает программу в системный
  трей (значок отражает состояние обхода; полный выход — через меню
  трея); хромированный 3D-дизайн (глянец, бевели, тени, градиенты по
  скруглениям); выбор языка интерфейса (Русский / English) и темы
  (Тёмная / Светлая / Полночь) с переключением на лету; явное включение
  TLS 1.2 для WinHTTP (проверка обновлений на Windows 7); GUID
  совместимости Windows 7/8 в манифесте; защита от второго экземпляра
  (повторный запуск разворачивает окно); GitHub Actions workflow для
  ручной сборки.
- **1.0.2**: если файлы zapret не найдены рядом с exe — GUI теперь
  автоматически ищет папку zapret (родительские папки до 3 уровней,
  подпапки с «zapret» в имени) и предлагает выбрать её вручную в
  диалоге с выбором папки; выбранная папка запоминается в
  `%APPDATA%\ZapretGUI\settings.ini`. Кнопка «ВКЛЮЧИТЬ ОБХОД» в этом
  состоянии превращается в «ВЫБРАТЬ ПАПКУ ZAPRET».
- **1.0.1**: исправлена формула расчёта размера шрифтов (ранее текст
  отрисовывался в ~100 раз крупнее, из-за чего интерфейс выглядел как
  набор цветных полигонов); исправлен расчёт масштаба при высоком DPI;
  отрисовка разделена на фазы GDI+/GDI (ранее состояние DC «текло»
  между перерисовками контролов); добавлен прозрачный фон у
  выпадающих списков; окно больше не «усыхает» на несколько пикселей
  из-за неправильного минимального размера.

## Как это работает

- **Запуск обхода** повторяет логику `general*.bat`: проверка, что служба
  не запущена, создание пользовательских списков, включение TCP
  timestamps (`netsh`), затем `winws.exe` стартует скрытно с аргументами,
  разобранными из выбранного `.bat` (полный разбор многострочных команд,
  раскрытие `%BIN%`, `%LISTS%`, `%GameFilterTCP%`, `%GameFilterUDP%`,
  преобразование `^!` → `!`).
- **Установка службы** повторяет `service.bat → Install Service`
  (создание службы `zapret` с автозапуском, описание, запуск, запись
  имени стратегии в реестр).
- **Состояния фильтров** хранятся в тех же файлах, что использует
  оригинальный `service.bat`, — GUI и bat-скрипты взаимозаменяемы.
- **Настройки GUI** (стратегия, папка zapret, язык, тема) хранятся в
  `%APPDATA%\ZapretGUI\settings.ini`.
- **Трей**: `Shell_NotifyIcon` (классический протокол — работает от
  Windows 2000 до 11); значки состояний рисуются в рантайме (32bpp ARGB).
  Перезапуск explorer.exe обрабатывается сообщением `TaskbarCreated`.
- **Windows 7**: PerMonitorV2 в манифесте игнорируется, отрабатывает
  фолбэк `dpiAware`; TaskDialog/DWM/IFileDialog загружаются
  динамически с фолбэками; для WinHTTP явно включаются TLS 1.1/1.2
  (без этого GitHub на Win7 SP1 не отвечает).

## Структура gui/

```
gui/
├── src/
│   ├── main.cpp      — окно, layout, отрисовка, трей, обработчики
│   ├── controls.cpp  — кастомные контролы (кнопки, тумблеры, дропдауны)
│   ├── uidraw.cpp/.h — хромированные примитивы: тени, глянец, бевели
│   ├── theme.cpp/.h  — палитры тем (тёмная/светлая/полночь), шрифты, layout
│   ├── lang.cpp/.h   — таблица строк RU/EN
│   ├── zapret.cpp    — ядро: парсер стратегий, службы, фильтры, статусы
│   ├── netops.cpp    — WinHTTP: версия, IPSet, hosts (+TLS 1.2 для Win7)
│   ├── applog.cpp    — цветной журнал на RichEdit
│   ├── common.h     — общие объявления
│   ├── controls.h   — API контролов
│   ├── zapret.h     — API ядра
│   ├── netops.h     — API сети
│   └── applog.h     — API журнала
├── res/
│   ├── app.ico       — иконка (генерируется скриптом)
│   ├── app.manifest  — requireAdministrator + PerMonitorV2 + Win7 GUID
│   └── app.rc        — подключение ресурсов
├── build.bat         — сборка на Windows
├── build.sh          — кросс-сборка на Linux
├── dist-README.txt   — README для скомпилированного архива
└── README-GUI.md     — этот файл
```
